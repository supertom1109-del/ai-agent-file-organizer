# 案例与复盘

以下案例从 Windows 本地整理经验提炼，示例目录中的文件均为虚构。

| 观察到的情况 | 可复用判断 | 首轮怎么验 |
|---|---|---|
| 同一份素材放在两个平台目录，内容一致 | 字节相同后仍要核对分发用途 | 两份都保留，理由注明用途 |
| 标为终版的合同是空模板，另一份才是签署件 | 查实际用途和签署内容，法律文件默认保护 | 分别说明模板与签署件的用途，均保留 |
| 两个主题目录都有同名文件 | 落点保留必要主题层级 | 两份都可提出归档，目标路径应不同 |
| 长跑任务结束后才产生正式结果 | 暂缓时记复查条件；以同范围基线对比增量 | 对样例在制品记暂缓和复查条件 |
| 脚本报改名成功，重新枚举发现未生效 | 用实际路径与指纹验收 | 首轮只读，用前后快照验证样例状态 |

## 收集哪些数据

每批收尾可填写[批次反馈记录](../templates/批次反馈记录.md)，按发生顺序留存发现、依据、修正和复验结果。

保留初始快照、原始计划、后续修订、时间线、终端输出和验收结果。记录实际模型标识、规程版本、执行时长、使用的工具、失败原因和人工介入次数。模型标识或耗时未测得就如实记录。文件数、目录数和总字节从基线分项读取。验收时从原始计划和基线计算文件覆盖、指纹核对与建议处置分布。阶段时间当场取系统时钟；只采集了部分阶段时，注明计时范围。

复盘时先按证据判断是范围理解偏差、内容误判、执行失败，还是检查器覆盖不足。优先把能复现的失败变成回归样例。先留住第一次实跑结果，修改规程或检查工具后用新批次再跑。复验历史批次时保留原始检查结果，用独立目录保存新结果。再用独立盲测样例检查新规则是否仍成立，判断者只读该轮样例。

## 本地试跑的验收范围

以下结果来自同一台 Windows 电脑上的虚构业务资料、隔离目录和独立验收。公开样例用于只读预演，实际操作按各批的独立计划执行和取证。

| 试跑 | 已验证结果 | 记录的偏差 |
|---|---|---|
| 只读预演 | 14 份样例与另一组 8 份样例均通过最终复验，前后快照一致。 | 首轮两项合理处置被旧检查器误判，原始结果保留。过程统计后来改由基线和计划汇总。 |
| 复制归档 | 2 个文件复制并核对指纹；重跑验证 2 个同内容跳过；1 个同名异内容目标的冲突被拦截。 | 执行说明记载清理了空暂存目录。规程已明确保留失败暂存件和空暂存目录。 |
| 改名与引用 | 一次改名核对内容指纹，2 处链接仅替换路径并实际打开，同名目标得到保护。 | 一条日志把「路径已消失」的值填入相反语义的字段。保留文件结果与日志核验两项结论。 |
| 系统回收与恢复 | 一个独立样例在动作前核实实际配额，回收索引匹配原路径和动作时间，系统还原后重读文件与基线一致。 | 早两次以估算配额开工，合规未通过。合规复验后仍观察到孤立回收索引，保留原状。 |

这批记录覆盖独立样例的预演和三类实际操作。跨卷迁移、批量文件及目录回收、并发抢占、中断恢复和其他 Windows 环境仍未验证。仓库分别提供只读计划检查和三类隔离操作的独立验收，见[实际试跑与验收](实际试跑与验收.md)。
