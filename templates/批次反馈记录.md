# 文件整理批次反馈记录

适用于只读预演和实际操作。每个批次单独留存，可记录正常完成、部分完成、受阻或没有发现。

## 批次概要

- 批次编号、规程版本与运行环境
- 开始及结束时间，按实测注明计时范围
- 原目标、实际执行范围、授权限制和仍待确认的范围
- 基线、计划、动作日志、期末快照和报告的位置；缺少的证据注明原因

## 发现

逐项写清阶段、预期、实测结果、原始证据位置、复现条件、已尝试的处理和遗留影响。前置失败、未遂动作、重试和后续验收分别记录。只有计划的项目继续标为计划。

| 阶段 | 预期 | 实测 | 证据位置 | 已尝试的处理 | 遗留影响 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 复核与同步

验证时读取实物及原始记录，独立确认问题所在。记录修复点、正例和反例结果、适用范围与未决事项。保留原始记录和历史失败。对可通用的改进，发布前用虚构或经确认可公开的材料制作案例，并记录公开提交链接。内部路径、原始业务记录与凭据留在本机。
