# AI 智能体文件整理

一套面向 Windows 项目资料的整理规程、试跑样例和验收工具。它帮助具备文件读取能力的智能体判断业务资料的用途、有效版本和归档位置，给出带证据的整理计划。用户确认后，才能另开具备相应权限的实际整理批次。

当前版本为 **v1.0.0**，作者为**钟代贤**，采用 [MIT 许可证](LICENSE)。样例为虚构资料。工具包采集基线、检查整理计划、准备隔离任务，并独立验收智能体执行的复制、改名和 Windows 系统回收与恢复。

## 第一次试跑

1. 在 Windows 安装 Python 3.12 或使用已有环境。检查工具仅使用 Python 标准库。
2. 在本目录打开 PowerShell，执行：

   ```powershell
   python -X utf8 tools/review.py before --run "../试跑记录/deepseek-r01"
   ```

3. 将 [DeepSeek 试跑任务](templates/DeepSeek首轮任务.md) 交给 DeepSeek。填入本仓库路径和上一步显示的记录目录绝对路径。限制本轮只读样例，只允许写入独立记录目录。
4. DeepSeek 完成后，在本目录执行：

   ```powershell
   python -X utf8 tools/review.py check --run "../试跑记录/deepseek-r01"
   ```

5. 将完整的 `deepseek-r01` 目录交回复盘。检查器会生成 `after.json` 和 `check.json`。每次重跑用新的记录目录。独立盲测可在建基线时加 `--sample holdout`；验收会自动读取基线中的样例范围。

## 实际操作试跑

先生成隔离样例和任务，再由用户授权 DeepSeek 或其他智能体执行。发起方使用检查工具核对实物与日志。操作范围、可运行命令及证据格式见[实际试跑与验收](docs/实际试跑与验收.md)。
