# 实际试跑与验收

在 Windows 使用 Python 3.12，从仓库目录打开 PowerShell。每个批次使用仓库外的一个新目录。将路径改为你自己的测试位置。

```powershell
python -B -X utf8 tools/rehearsal.py prepare copy --run "../runs/copy-01"
python -B -X utf8 tools/rehearsal.py prepare rename --run "../runs/rename-01"
python -B -X utf8 tools/rehearsal.py prepare recycle --run "../runs/recycle-01"
```

每条命令会生成一组虚构样例、独立期初基线、操作计划和一份已填路径的 `任务.md`。先审阅计划，再把对应任务交给 DeepSeek 或其他具备本地文件能力的智能体。授权限定在隔离样例及计划所列动作。

| 场景 | 由发起方独立核验 |
|---|---|
| `copy` | 两份副本、实际目标路径、与源件一致的 SHA-256、重跑快照、同名冲突的保护。 |
| `rename` | 旧路径与新路径状态、内容指纹、两处引用只改授权路径、两条稳定链接和同名冲突。 |
| `recycle` | 真实配额与占用、Windows 回收索引的原路径与时刻、匹配实体的记录、恢复原位文件的实际指纹和匹配实体的消失。 |

系统回收任务会在回收前运行一次 `capacity`，该命令只读取 Windows 配额和占用，将结果保存在测试目录。设置或占用查不到时保留样例并标记受阻。回收证据按当前 Windows 用户及对应卷核对。恢复后若只剩本次回收索引，作为观察记录。

执行完成后，由发起方根据实际创建的批次运行对应检查：

```powershell
python -B -X utf8 tools/rehearsal.py check --run "../runs/copy-01"
python -B -X utf8 tools/rehearsal.py check --run "../runs/rename-01"
python -B -X utf8 tools/rehearsal.py check --run "../runs/recycle-01"
```

每个批次生成独立的 `check.json`，原始记录保留。日志、快照及操作声明均与磁盘实物交叉复核。若计划只执行了一部分、证据有矛盾或检查失败，报告实际错误，重跑使用新目录。智能体是否选对了真实业务版本和用途，仍需结合内容证据复核。

实际操作试跑只支持这三组预定义隔离样例。对业务目录的清理、跨卷迁移、批量回收、并发抢占和中断后恢复，需要独立计划、授权和验收。本机实测范围见[案例与复盘](案例与复盘.md)。
